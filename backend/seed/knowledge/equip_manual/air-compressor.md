## 1. 排气温度报警机制

本手册适用于 AC-02（阿特拉斯 GA-55 螺杆式空压机，排气量 9.5 m³/min，排气压力 7-10 bar）及同型号设备。

排气温度报警阈值：
- 正常运行温度：75-95℃
- 一级报警：95℃（指示灯黄色，提示维护）
- 二级报警：105℃（指示灯红色，自动降载）
- 停机保护：110℃（自动停机，禁止复位启动）

排气温度传感器位于油气分离器出口。温度信号接入控制器，触发报警与停机逻辑。

## 2. 排气温度报警排查

排气温度升高的常见原因：

1. 冷却系统故障（最常见，占 60%）
   - 冷却风扇停转：检查风扇电机、皮带、接触器
   - 冷却器堵塞：散热翅片积尘、油垢，散热效率下降
   - 冷却水流量不足（水冷型）：检查水阀、水泵、过滤器

2. 润滑油问题（占 20%）
   - 油量不足：油位计低于最低刻度，补充至中间刻度
   - 油液老化：粘度下降、添加剂耗尽，热容量降低
   - 油品不匹配：使用非指定油品，导致积碳

3. 温控阀故障（占 10%）
   - 温控阀卡死在全短路位置：油液不经过冷却器，直接进机头
   - 温控阀芯磨损：动作不灵敏

4. 机头故障（占 5%）
   - 转子磨损：内漏增大、压缩效率下降、发热
   - 轴承损坏：摩擦发热、异响

5. 环境因素（占 5%）
   - 环境温度过高：机房通风不良，> 40℃
   - 进气温度高：空气滤清器堵塞、吸气位置不当

排查步骤：
1. 观察冷却风扇是否运转、有无异常振动
2. 检查冷却器散热翅片是否清洁（压差或目视）
3. 检查油位与油色（发黑或乳化说明油液老化）
4. 测量温控阀前后温度差（温差 < 5℃ 判定温控阀故障）
5. 检查空气滤清器压差指示器
6. 测量机房环境温度与通风

## 3. 冷却系统维护

风冷型冷却器维护：
1. 每周检查散热翅片积尘情况
2. 每月用压缩空气反吹清洁（0.5 bar 以下，避免翅片倒伏）
3. 每季度检查风扇皮带张紧度（按压 10mm 为宜）
4. 每年拆洗冷却器（专用清洗剂，避免损伤铝翅片）

水冷型冷却器维护：
1. 每周检查冷却水流量与进出水温差
2. 每月检查水过滤器
3. 每季度反冲洗冷却器水侧
4. 每年化学清洗（除垢剂循环 4-6 小时）

温控阀维护：
1. 每年校验温控阀动作温度（70℃ 开始开启，85℃ 全开）
2. 卡涩时拆洗阀芯，必要时更换

## 4. 润滑油管理

指定油品：阿特拉斯 Roto-Injectate 螺杆油（或等效替代品，需通过认证）

换油周期：
- 首次换油：500 小时（新机或大修后）
- 正常换油：4000 小时或 12 个月（以先到为准）
- 恶劣工况：2000 小时（高温、高湿、多尘环境）

换油步骤：
1. 运行 10 分钟，油温 60℃ 以上停机
2. 排油（油气分离器、机头、冷却器三处）
3. 更换油气分离器芯与油过滤器
4. 加注新油至油位计中间刻度
5. 启动运行 5 分钟，复检油位

油液状态判定：
- 清澈琥珀色：正常
- 深棕色：氧化，临近换油
- 乳白色：进水，立即停机
- 黑色且有焦味：过热，检查温控阀与冷却系统

## 5. 机头故障诊断

螺杆机头（主机）故障模式：

1. 转子磨损：排气量下降、排气温度升高、电流上升
2. 轴承损坏：异响（金属敲击）、振动、温升
3. 密封泄漏：漏油、压缩效率下降

诊断方法：
1. 测量排气量（流量计），与额定对比，< 80% 需大修
2. 测量电流（额定电流下），> 额定 110% 判定机械摩擦
3. 振动测试（机头壳体），速度 > 4.5 mm/s 判定轴承损坏
4. 异响判定（金属敲击为轴承，气流尖啸为内漏）

大修周期：
- 15000-20000 运行小时：预防性大修（更换轴承、密封）
- 排气量 < 80% 额定值：计划大修
- 严重异响或振动：立即大修

备件清单：
- 螺杆油 Roto-Injectate（45L）
- 油气分离器芯（型号 1622116800）
- 油过滤器（型号 1611-9300-10）
- 空气滤清器芯（型号 1613-7300-00）
- 温控阀芯（型号 1202-5300-00）
- 进气阀维修包

## 6. 安全保护与紧急停机

紧急停机条件：
1. 排气温度 > 110℃
2. 电机电流 > 额定 130%
3. 机头异响突变
4. 油位骤降（漏油）
5. 振动突变

复位流程：
1. 按急停按钮
2. 排查故障原因
3. 清除报警（控制器复位）
4. 手动盘车确认无卡涩
5. 启动空载，观察 10 分钟
