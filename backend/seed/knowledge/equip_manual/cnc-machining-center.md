## 1. 主轴系统结构与维护

本手册适用于 CNC-07（VMC-850 立式加工中心）及同型号设备。主轴最高转速 10000rpm，采用 BT40 锥孔，前轴承为角接触球轴承 7014C（型号 7014C，P4 精度），后轴承为 NN3022K 双列圆柱滚子轴承。

主轴轴承润滑采用脂润滑，正常使用寿命 20000-25000 运行小时。累计运行小时超过 20000 小时后建议安排预防性更换。

主轴温升标准：连续运转 8000rpm 时，前轴承外壳温度应低于 45℃，后轴承低于 50℃。超过标准需停机检查。

## 2. 振动故障诊断

主轴在 8000rpm 以上出现周期性振动是轴承早期故障的首要预警特征。诊断流程：

1. 使用振动分析仪在主轴前轴承座处采集频谱
2. 重点观察轴承故障特征频率：
   - BPFO（外圈故障频率）：通常为转频的 6-8 倍
   - BPFI（内圈故障频率）：通常为转频的 8-10 倍
   - BSF（滚动体故障频率）
   - FTF（保持架故障频率）
3. 若 1×BPFO 幅值超过 2.5 mm/s（ISO 10816 V/4 级），判定为外圈点蚀或磨损
4. 若 1×转频幅值偏高，检查动平衡；2×转频偏高，检查对中

振动值标准（前轴承座，8000rpm）：
- < 1.8 mm/s：正常
- 1.8-2.5 mm/s：警戒，安排监测
- 2.5-4.5 mm/s：异常，计划停机检修
- > 4.5 mm/s：危险，立即停机

## 3. 加工表面振纹分析

加工表面出现振纹（周期性刀痕）通常与以下原因相关：

1. 主轴轴承磨损：振动特征频率与刀齿切入频率（刃数×转速）发生共振，表面振纹间距等于每齿进给量
2. 主轴动平衡不良：不平衡量超过 G2.5 级，高速时离心力激发振动
3. 刀具系统问题：刀柄锥面磨损、拉刀力不足导致刀柄松动
4. 伺服系统振荡：驱动增益参数不匹配

诊断步骤：
1. 测量振纹间距，计算振动频率 = 进给速度 / 振纹间距
2. 对比主轴转频与轴承故障频率，判断共振源
3. 检查动平衡状态（动平衡机或现场平衡仪）
4. 检查刀柄 BT40 锥面接触状态（红丹粉着色检查）

## 4. 轴承故障特征与判定

角接触球轴承 7014C 故障模式：

1. 外圈点蚀（BPFO）：最常见，疲劳剥落始于滚道次表面，频谱 1×BPFO 明显，伴随 2×、3×谐波
2. 内圈点蚀（BPFI）：频谱 1×BPFI + 边带（转频调制）
3. 滚动体故障（BSF）：频谱 BSF + FTF 调制
4. 保持架断裂（FTF）：低频域 FTF 幅值显著

判定标准：
- 单一 1×BPFO > 2.5 mm/s：外圈早期点蚀，建议 2 周内更换
- 1×BPFI > 3.0 mm/s：内圈故障，建议 1 周内更换
- BSF 或 FTF 显著：立即停机

备件建议：
- 角接触球轴承 7014C（P4 精度，原厂件）
- 双列圆柱滚子轴承 NN3022K
- 主轴密封件套件

## 5. 动平衡校正

主轴动平衡标准 G2.5 级（ISO 1940）。校正流程：

1. 拆下卡盘或刀柄
2. 在动平衡机上检测不平衡量
3. 在主轴后端平衡环上去重或配重
4. 复检至 G2.5 级

现场动平衡（不拆卸）：使用现场平衡仪，在主轴后端配重面加重块。

## 6. 日常保养与巡检

每日检查：
- 主轴温升（手触或测温枪）
- 异响（尖锐啸叫多为润滑不良，低沉隆隆声多为轴承磨损）
- 振动（简易振动笔，与基线对比）

每 500 运行小时：
- 检查润滑脂状态
- 检查冷却水流量
- 检查刀柄拉钉磨损

每 2000 运行小时：
- 振动频谱采集
- 动平衡复检
- 精度检验（球杆仪圆度测试）

## 7. 紧急停机条件

立即按急停并报告：
1. 振动突变（幅值翻倍以上）
2. 主轴温升超过 60℃
3. 异响突变（尖锐声或金属敲击声）
4. 加工尺寸突变（直径或长度超差 0.05mm 以上）
